PRUEBA DE HIPÓTESIS PARA LA DIFERENCIA DE MEDIAS

Comparación de medias

Para realizar la comparación de las medias de dos poblaciones debemos tener en cuenta si comparamos poblaciones independientes o queremos evaluar las diferencias entre las observaciones de un mismo individuo. Según lo que necesitemos testar es el tipo de prueba que se debe considerar; pues hay diferentes pruebas de hipótesis para la media: Prueba T para muestras independientes y Prueba T para muestras apareadas (o de medidas repetidas).

Prueba para muestras independientes

La prueba t de Student para datos independientes se utiliza cuando deseamos comparar las medias entre dos grupos (por ejemplo deseamos saber si la altura varía según el género).

Esta prueba se aplica cuando el investigador desea estudiar la tendencia de una variable dependiente o respuesta cuantitativa (Y), medida en escala de intervalo o de razón distribuida normalmente, en función de una variable independiente o factor con dos niveles, tal que las unidades de análisis clasificadas en cada nivel del factor, son diferentes, por lo que se tendrán dos muestras independientes.

Para realizar dicha comparación es necesario validar el supuesto homogeneidad de las varianzas de los grupos; dado que el estadístico que se calcula varía ligeramente en base a si las varianzas de los dos grupos en estudio son conocidas, desconocidas pero iguales o desconocidas y distintas. Por esto debe realizarse en forma complementaria la prueba de homogeneidad de las varianzas; que nos permitirá conocer si las varianzas de los dos grupos de observaciones son o no iguales. Existen distintas pruebas de homogeneidad de la varianza, la prueba F, la prueba de Levene (que es la que utiliza el Jamovi).

Prueba de hipótesis para la

comparación de proporciones

En muchas ocasiones se debe comparar la proporción de un grupo con la de otro, en relación con alguna característica en común. Por ejemplo, puede querer compararse la proporción de fabricación de un producto por dos empresas que compiten entre sí. Para realizar la comparación de proporciones o de porcentajes de éxitos de dos poblaciones con muestras suficientemente grandes, basados en el teorema central del límite, es posible utilizar la distribución normal para realizar la prueba de diferencia de proporciones. En caso que las muestras sean pequeñas; no es posible utilizar la distribución nomal, los métodos de resolución son mas complicados.

Ejemplo 3

Dos grupos A y B de empresas fueron sometidos a diferentes programas de protección contra ataques cibernéticos. A las 110 empresas del grupo A se les implementó un nuevo sistema de ciberseguridad, obteniéndose que 77 de ellas no sufrieron ataques exitosos durante un periodo de evaluación. Por otro lado, a las 300 empresas del grupo B se les aplicó el sistema tradicional, y 180 de ellas no sufrieron ataques exitosos en el mismo periodo. Se desea determinar, con un nivel de significación del 2,5%, si el nuevo sistema de ciberseguridad es brinda mayor protección que la del sistema tradicional.

Hip investigación: si el nuevo sistema de ciberseguridad es brinda mayor protección que la del sistema tradicional, entonces el porcentaje de empresas que no sufrieron ataques con el nuevos sistema es mayor al porcentajes que no sufrieron ataquen con el sistema tradicional.

Ejemplo 5

Una empresa tecnológica quiere analizar el nivel de retención de usuarios en su plataforma digital de gestión de proyectos. Se seleccionaron dos grupos de usuarios: los que utilizan principalmente la aplicación móvil y los que utilizan principalmente la versión web. Se considera usuario retenido aquel que continúa utilizando activamente la plataforma durante los últimos 4 meses. De 2200 usuarios que utilizan la aplicación móvil 1530 siguen activos; mientras que de 3800 que utilizan la versión web 2648 siguen activos.

¿Puede concluirse, con un nivel de significación del 5% que la proporción de retención es mayor en la versión web que en la aplicación móvil.?
